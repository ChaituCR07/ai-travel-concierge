# 1. Phase 1 Tech Stack Selection

Date: 2026-10-20

## Status
Accepted

## Context
We need a robust, scalable, modern stack for the AI Travel Concierge.

## Decision
- Backend: Python 3.11 with FastAPI and SQLAlchemy
- Frontend: Next.js with TypeScript and Vitest
- Database: PostgreSQL with Alembic migrations
- CI: GitHub Actions for linting, testing, and repo hygiene
