# AI Travel Concierge

An intelligent travel planning and concierge application.

- `backend/`: FastAPI application, database models, and service layer.
- `frontend/`: Next.js / React frontend interface.
- `docs/`: System documentation, architecture decision records, and release notes.
- `scripts/`: Operational and smoke testing scripts.
